Simpan / Ekspor

Kerja tim paralel: tiap perangkat punya kode sendiri (lihat Data Umum) yang masuk ke ID titik, jadi tim Struktur, Arsitektur, MEP bisa mengisi butir/tahap/gedung yang berbeda — atau bahkan butir yang sama — tanpa bentrok. Tiap akhir hari: Ekspor JSON → kirim ke koordinator → koordinator Impor/gabung semua file (boleh sekaligus banyak file). Titik digabung berdasarkan ID; penilaian butir Lampiran 2 diisi dari perangkat lain bila di sini masih kosong, dan bila dua perangkat menilai butir yang sama secara berbeda, impor akan melaporkannya untuk diputuskan ahli. File gabungan hasil impor bisa diekspor lagi sebagai JSON induk.
